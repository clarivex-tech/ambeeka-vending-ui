# UX Mockup Package

## Current source of truth

- `dashboard.html` is a dashboard visual exploration based on the business settlement screenshot; its dashboard figures are illustrative sample data.
- `weekly-upload.html`, `pricing-review.html`, `calculation-result.html`, `pricing-catalog.html`, and `pricing-form.html` are the current workflow and pricing mockups.
- `weekly-billing-mockups.css` contains the shared responsive styling. Primary teal is `#00685F`.
- `weekly_pos_billing_state_matrix.md` defines interaction states.
- `weekly_pos_billing_pricing_crud_specs.md` defines screen behavior and the confirmed scope.
- `kinetic_emerald/DESIGN.md` records the visual direction and PrimeNG mapping.

All displayed names, IDs, dates, counts, and prices are sample data. The older Stitch exports in the screen folders are retained as historical visual references; use the files above for the current flow and API assumptions.
